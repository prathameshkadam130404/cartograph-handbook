# Cartograph: the team handbook

Live site: https://prathameshkadam130404.github.io/cartograph-handbook/

A plain-language, interactive handbook for the team: what we are building (certified checks of AI decision models we can only query), who pays, why now, the market, how we make money, the 36-month plan with gates, what we need, the risks, and a glossary.

"Cartograph" is a working name. Figures marked "assumption" on the site are placeholders to test, not forecasts.

## Files

- `index.html` — page content
- `style.css` — design (light and dark themes)
- `app.js` — animations, charts and interactive pieces (no external libraries)

## Editing

Edit any file on GitHub and commit to `main`. GitHub Pages republishes automatically within a minute or two.
